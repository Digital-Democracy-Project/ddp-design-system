# Design-sync notes

## Re-sync risks

- **Tier 4 legacy token aliases were deleted from `colors_and_type.css` (2026-08-25), including `--ddp-font-script`.** This is expected to break `preview/14-tagline.html` and `ui_kits/marketing-site`'s `HeroBanner` in the Claude Design project, both of which reference `var(--ddp-font-script)` directly — user-confirmed acceptable, to be fixed properly later by migrating those to real design-system patterns rather than restoring the legacy alias. Neither file is touched by this sync (see the sync plan below), so they'll break in place until that migration happens. The `[FONT_MISSING]` warning this previously caused no longer fires, since the variable itself is gone, not just its font file.
- **`dist/style.css` is now self-sufficient** (tokens + component CSS merged at build time in `vite.config.ts`, tokens first) — the `cssEntry` override this config previously needed is gone; auto-detection finds everything correctly on its own now.
- **The raw Sass sources and `styles/README.md` are NOT part of this skill's standard managed paths** (`writes` only covers `components/**`/`fonts/**`/`_vendor/**`/`_preview/**`/`guidelines/**`/`styles.css`/`README.md`/the bundle+anchor files — nothing under `styles/`). `resync.mjs`'s own computed diff will NOT include them, so keeping them in sync has to be done manually on each sync (extend the `finalize_plan`/`write_files` calls), or they silently drift stale. The current set is `styles/colors_and_type.scss`, `styles/_spacing.scss`, `styles/core/index.scss`, `styles/core/tokens/index.scss`, `styles/core/_functions.scss`, `styles/core/_breakpoints.scss`, `styles/core/_mixins.scss`, `styles/core/_tones.scss`, and `styles/README.md`. The compiled tokens need no manual step: they ship inside `dist/style.css`, which the sync manages as `styles.css`.
- **The Claude Design project holds stale copies of the old Sass layout.** On 2026-08-25, at explicit user request, `styles/_tokens.scss`, `_mixins.scss`, `_breakpoints.scss`, `index.scss`, `styles/README.md` and the root `colors_and_type.css` were pushed as a manual, one-off addition to the normal component sync. Since then the tokens moved to `styles/core/tokens/index.scss`, the other partials to `styles/core/`, and `colors_and_type.css` became `styles/colors_and_type.scss` (2026-10-05). On the next sync, push the current set above and remove or replace those old paths, including the root `colors_and_type.css`.
